# ScriptGuard

ScriptGuard is an open‑source browser privacy extension designed to give users full control over scripts, fingerprinting, WebRTC leaks, Blob leaks, and third‑party tracking all while keeping sites usable in PRO mode and fully locked down in MAXIMUM mode.

Built for maximum privacy, zero telemetry, and full transparency.
⚡ Features

Every feature below is implemented according to the ScriptGuard Master Prompt.
🔐 Privacy Modes

    OFF — No protection

    BASIC — Light blocking, safe for all sites

    PRO — Privacy‑focused but usable

    MAXIMUM — Nuclear mode (delete everything)

🛡️ Privacy Shields

    WebRTC Kill‑Switch

    Blob URL Kill‑Switch

    Fingerprint Request Deletion

    Third‑Party Script Blocking

    Heuristic Tracking Detection

🎨 Fingerprinting Protection

    Canvas fingerprint deletion

    WebGL fingerprint deletion

    Audio fingerprint deletion

    Hardware entropy protection

    Font enumeration limiting

🌐 IP Leak Protection

ScriptGuard blocks:

    WebRTC IP leaks

    STUN/ICE leaks

    Blob worker leaks

    Fingerprinting‑based IP inference

ScriptGuard cannot spoof or hide your public IP — only VPN/Tor can. 
If you want to hide your public IP is recommend to use a VPN.

📜 Whitelisting System

    Global whitelist

    Per‑site whitelist

    Regex rules

    Heuristic learning rules

📤 Import / Export

    Export all rules as JSON

    Import JSON to restore configuration

🧪 Reporting System

    Generate a full privacy report

    No telemetry

    No automatic sending

    User manually copies/pastes

🧩 Installation

Firefox

    Download the repository

    Go to about:debugging#/runtime/this-firefox

    Click Load Temporary Add‑on

    Select manifest.json

    Make changes, test in your browser, and submit pull requests.
